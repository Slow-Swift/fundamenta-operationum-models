Models from Fundamenta Operationum by Regiomontanus

This page serves as an exploration of software for creating digital models of mathematical diagrams for spherical trigonometry.

In my opinion the gold standard example of similar models is this quaternion visualization by Ben Eater and 3Blue1Brown. It builds on MANIM to essentially make an interactive video, explaining quaternions in a way that is both intuitive and beautiful. Unfortunately, they never continued with similar projects and never made the code public so we don't have the code to work with. The closer we can come to replicating this, the better.

Three.js

Three.js is a Javascript library for making 3D scenes. This provides the highest level of customizability but also requires the most work. However, with this it may be possible to make quite good interactive models.

Sample models I made for Proposition 2 and Proposition 14 can be found here.

Desmos 3D

Desmos 3D is what I used for the models I made in class. While it worked well enough at the time it probably isn't good enough for professional models. For one thing there is no option to hide the clipping box which can look quite ugly. (It is possible to hide the box by starting from desmos.com/3d/hidethebox but this seems like a hack and I have no idea if it will continue to be supported). Other problems include the lack of proper zooming and panning of the model, and that there is no way to get rid of the expression list (at least that I know of while embedding it). That being said, I was able to get a decent set of helper functions that allowed me to make complex models without too much time. However, I think maintaining a growing function library in the expression list would become quite a chore. Also Desmos 3D has no way to add labels to points.

It is quite easy to embed a Desmos 3D graph in a webpage. However, this means we are reliant on Desmos servers to keep the models up and running.

Geogebra

Geogebra seems better than Desmos 3D in that it is not subject to some of the restrictions such as bad movement, the clipping box, and lack of labels. However, like Desmos the algebra list might be quite hard to maintain. I found it quite a challenge to work out how to properly implement some of the arcs for the models as it works quite differently from Desmos for defining geometry. This means that much less can be shared between each model compared to Desmos making it take longer.

Others

MANIM is a python library for creating mathematical animations and can make really great ones. However, as far as I can work out there is no way to turn it into an interactive model.

JSX Graph is another web-based approach similar to THREE.js but may provide more of a starting base. I only just discovered this and haven't had time to test, but could end up being between Desmos and THREE.js with the ease of use of Desmos but freedom of THREE.js.
